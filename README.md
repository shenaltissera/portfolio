# Data Science Portfolio

A responsive one-page portfolio website tailored for a data science, machine learning, or analytics professional.

## Customize

- Replace `Alex Carter` and contact links in `index.html` with your own details.
- Update the project cards with real case studies, repositories, notebooks, or dashboards.
- Swap the metrics for outcomes from your own work.
- Edit the skills and experience sections to match your background.

## Run locally

Open `index.html` in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
